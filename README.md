# W OPTICS — Солнцезащитные очки для зрения 2 в 1

Одностраничный лендинг для предзаказа солнцезащитных очков с магнитной насадкой и антибликовым покрытием.

## Стек
- HTML5, CSS3 (встроенные стили), Vanilla JS (без внешних зависимостей)
- Canvas-анимация фона с интерактивностью по движению мыши
- IntersectionObserver для появления элементов при скролле
- Адаптивная вёрстка (мобильные/десктоп)
- Поддержка `prefers-reduced-motion`

## Структура
```
w-optics-site/
├── index.html
└── assets/
    └── images/
        ├── logo.png
        ├── banner1.png
        ├── banner2.png
        ├── base-glasses.png
        └── sun-antiglare.png
```

## Деплой
Сайт совместим со статическим хостингом (GitHub Pages, Netlify, Vercel).
Все ссылки используют относительные пути (`assets/images/...`),
поэтому корректно работает как из корня домена, так и из подпапки (например, `/<repo>/`).

## Локальный запуск
Открыть `index.html` в браузере или поднять любой статический сервер:
```bash
cd w-optics-site
python -m http.server 8000
# http://localhost:8000
```
