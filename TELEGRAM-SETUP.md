# Настройка приёма заказов в Telegram

Сейчас `TG_ENDPOINT` в `assets/js/site.js` пустой: автоматической отправки нет. Сайт готовит текст заявки, покупатель копирует его и сам отправляет в Telegram. До отправки продавец заявку не получает. Закрытие страницы не сохраняет её у продавца.

Автоматический приём требует отдельно согласовать передачу имени, телефона, рецепта и адреса в Telegram, настроить секреты и проверить сервер. Код Worker пока не развёрнут. Цена 2 990 рублей включает обычные сферические линзы, диоптрии двух глаз могут отличаться. Рецепт и межзрачковое расстояние проверяются до изготовления. Оплата только после подтверждения рецепта, сроков и доставки.
Нужно сделать **один раз**, ~10 минут. В конце — прислать мне URL воркера, я подключу его к сайту.

## 1. Создать бота (2 минуты)

1. В Telegram найдите **@BotFather** и откройте чат
2. Отправьте `/newbot`
3. Придумайте имя, например: `W Optics Orders`
4. Придумайте username (латиницей, заканчивается на `bot`), например: `woptic_orders_bot`
5. BotFather пришлёт **токен** вида `123456789:AAH...xyz` — сохраните его

## 2. Узнать свой chat_id (1 минута)

1. Откройте чат со **своим** ботом (по username из шага 1) и отправьте ему любое сообщение, например `привет`
2. В браузере откройте (подставьте свой токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. В ответе найдите `"chat":{"id":` — это **ваш chat_id** (число, может быть отрицательным)

## 3. Развернуть воркер на Cloudflare (5 минут, бесплатно)

1. Зарегистрируйтесь на **dash.cloudflare.com** (бесплатный тариф)
2. Слева: **Workers & Pages** → **Create** → **Create Worker**
3. Имя, например `woptic-orders` → **Deploy**
4. Нажмите **Edit code** → удалите всё в редакторе → вставьте содержимое файла `worker-telegram.js` → **Deploy**
5. Настройки воркера → **Variables and Secrets** → тип **Secret**:
   - `BOT_TOKEN` = токен из шага 1
   - `CHAT_ID` = число из шага 2
   → Save → **Deploy** (ещё раз)
6. Скопируйте URL воркера вида `https://woptic-orders.<ваше-имя>.workers.dev`

## 4. Подключить к сайту

Перед подключением обновите Worker: фронтенд считает отправку подтверждённой только при HTTP 2xx и JSON `{"ok":true}` после успешного ответа Telegram. Текущий шаблон Worker возвращает текст `ok`, поэтому пока несовместим с этим контрактом. Без обновления и проверки оставьте `TG_ENDPOINT` пустым. Нужны проверка обязательных полей на сервере, пересчёт цены 2 990 × количество и ограничение злоупотреблений; шаблон не прошёл проверку готовности к запуску.

Присылаете мне URL воркера — я вставлю его в `assets/js/site.js`
(строка `const TG_ENDPOINT = '...'`) и залью сайт на хостинг.

Если хотите сделать сами: в `assets/js/site.js` найдите `const TG_ENDPOINT = '';`
и вставьте URL между кавычками, затем обновите файл на хостинге по FTP.

## 5. Проверка

Откройте https://woptic.annakam.ru → любой пункт «Заказать» →
пройдите мастер до конца → на шаге 3 нажмите «Оформить заказ».
В Telegram должно прийти сообщение с заказом.
До подключения сайт показывает текст заявки для ручной отправки. Только отправленное покупателем сообщение поступит продавцу.

## Оплата

Оплата согласуется с покупателем после проверки рецепта, возможности изготовления, сроков и доставки. Не размещайте непроверенный QR-код в форме заявки и не просите оплату до подтверждения заказа.
